# VoxVector audit archive

This directory is the organized audit archive requested by Daren on September 7, 2026. Original records remain in place and retain their authority. Copies are historical snapshots, not newly verified statements about production.

Read [AUDIT_INSTRUCTIONS.md](AUDIT_INSTRUCTIONS.md) before auditing and [AUDIT_REPORT.md](AUDIT_REPORT.md) for current progress. [SOURCE_INDEX.md](SOURCE_INDEX.md) maps every copied record to its original path and SHA-256. The machine-readable equivalent is `manifest.json`.

| Directory | Contents |
| --- | --- |
| Documentation_Audits | Documentation alignment and repository documentation reviews |
| Engineering_Audits | Engineering audits and system state reports |
| Runtime_Audits | Deployment, cloud, speech provider and runtime audits |
| QA_Audits | QA status, hardening and method QA records |
| Historical_Checkpoints | Dated project checkpoints |
| Repository_Audits | Main repository audit records and supporting maps |
| Evidence_Snapshots | Existing frontend audit data preserved as source evidence |

Each category preserves the original repository path beneath it, preventing filename collisions and preserving distinctions between canonical documents and Bible mirrors. Relative links inside byte-identical copies retain their original meaning at the original source location; use SOURCE_INDEX to open that location. Do not interpret a broken relative link in a snapshot as a broken canonical document link.

Scope: tracked audit reports, audit-directory records, documentation alignment reviews, QA records, engineering state reports, runtime incident records, project checkpoints and the existing frontend audit-data source. This is not an export of private customer logs, audio, transcripts, credentials, or all cloud telemetry. Those require a separate scoped export and access review. No original files are moved or deleted.
