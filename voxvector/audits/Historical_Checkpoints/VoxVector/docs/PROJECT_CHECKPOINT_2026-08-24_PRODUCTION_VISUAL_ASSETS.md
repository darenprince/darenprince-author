# VoxVector Production Visual Asset Pack — 2026-08-24

## Scope

Created a production-ready visual asset set for the canonical VoxVector React application and its social/editorial surfaces.

## Asset dimensions

### Website backgrounds

All website backgrounds are 1920×1080 SVG assets:

- `voxvector-bg-waveform-1920x1080.svg`
- `voxvector-bg-network-1920x1080.svg`
- `voxvector-bg-audio-signal-1920x1080.svg`
- `voxvector-bg-topography-1920x1080.svg`
- `voxvector-bg-hex-grid-1920x1080.svg`

These are intended for full-width hero, section, divider, or atmospheric background use. They contain no fabricated telemetry or analytical results.

### Editorial / blog

All editorial assets are 1200×628 SVG assets:

- `voxvector-blog-science-of-voice-1200x628.svg`
- `voxvector-blog-evidence-analysis-1200x628.svg`
- `voxvector-blog-surface-patterns-1200x628.svg`
- `voxvector-blog-evidence-path-1200x628.svg`

### X / Twitter OG

All social assets are 1200×675 SVG assets:

- `voxvector-og-truth-has-a-voice-1200x675.svg`
- `voxvector-og-evidence-over-assumption-1200x675.svg`
- `voxvector-og-patterns-dont-lie-1200x675.svg`

## Design boundary

The assets follow the active VoxVector visual language: black, white, gray, restrained contrast, technical evidence imagery, and clean typography. They do not use synthetic analysis metrics or imply that decorative graphics are scientific measurements.

## Integration boundary

The assets are staged under:

`voxvector/public/assets/marketing/`

The canonical landing page currently uses the existing hero cinematic asset. This change adds the new production asset library without replacing or duplicating existing page implementations.

## Verification

Repository source was inspected before asset creation. The assets were created on the feature branch `feature/voxvector-production-visual-assets`. No production deployment or browser verification is claimed by this checkpoint.
