# VoxVector Warm Card Refinement — 2026-08-19

## Scope

Public landing page visual refinement based on the supplied mobile reference.

## Implemented

- Reduced background contrast behind the technology section so charcoal remains quiet rather than competing with the method surfaces.
- Lifted the primary dark charcoal surface from the prior near-black value to a restrained warm charcoal.
- Restored the approved coffee, copper and muted gold accent family through the shared VoxVector CSS variables.
- Converted the technology method rows into subtle cards with a low contrast coffee-to-neutral gradient.
- Kept the gradient deliberately restrained so it reads as surface depth rather than a high-contrast panel effect.
- Added small 4px corner radii to the technology cards and other square bordered/interactable public surfaces for visual consistency.
- Preserved the existing responsive layout, typography, icons and analytical content.

## Boundary

This is a presentation-only change. It does not alter VoxVector analysis, evidence extraction, classification, reliability logic, API behavior, or scientific validation status.

## Verification status

The CSS change is committed to the public React workspace. Browser-level visual QA and a fresh production build remain required before claiming rendered production verification.
