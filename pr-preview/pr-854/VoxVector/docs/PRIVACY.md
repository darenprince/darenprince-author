# VoxVector Privacy Policy

## Purpose

This policy describes the intended privacy principles for the VoxVector public application and analysis platform.

VoxVector is designed around privacy conscious vocal analysis. Audio should be collected and processed only for a defined user purpose and only through supported application workflows.

## Audio and analysis data

Audio submitted for analysis may contain sensitive personal information. The application should minimize collection, avoid unnecessary retention, and expose clear processing states. The current public landing page does not collect or analyze audio.

When analysis services process audio, retention and storage behavior must follow the active backend configuration and documented product contract. The interface must never imply deletion, encryption, retention, or sharing behavior that has not been implemented and verified.

## Developer access

Developer Console access uses Supabase Auth and a trusted developer role. Authentication credentials are not hard coded into the public application.

## Third party services

VoxVector uses infrastructure and service providers documented by the project architecture. Their involvement must be reflected accurately in deployment and data handling documentation.

## Changes

This document is a product policy record and should be reviewed by qualified counsel before being treated as a final legal privacy notice.

## Contact

Use the project contact channel published by the owning organization for privacy questions or requests.
