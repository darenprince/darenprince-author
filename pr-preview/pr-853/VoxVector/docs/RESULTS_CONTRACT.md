# VoxVector Results Contract

A result must preserve:

- run identifier
- schema version
- eligibility/reliability state
- measured observations
- evidence records and provenance
- candidate state
- final disposition
- limitations and uncertainty
- alternative explanations
- input and software provenance

`indeterminate`, `insufficient_evidence`, and `abstain` are valid outputs.

No result field may imply that an acoustic or linguistic observation is intrinsically a deception label. Final disposition is authorized only by explicit validation and reliability gates.
