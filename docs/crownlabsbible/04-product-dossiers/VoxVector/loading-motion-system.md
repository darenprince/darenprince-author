# VoxVector Loading Motion System

Canonical source: `VoxVector/docs/LOADING_MOTION_SYSTEM.md`.

The VoxVector loading system uses five distinct visual states:

1. **Analysis engine** — Esca-Byte / Hard Penguin 57 reference, adapted to the VoxVector palette.
2. **Decoding** — bilal_9731 / New Moose 50 reference, adapted as a chart-like decoding/progress treatment. Uiverse labels the reference a “Candle Loader.”
3. **Analysis workspace** — Shoh2008 / Terrible Fireant 25 reference.
4. **API startup** — Satwinder04 / Witty Starfish 81 reference.
5. **Application splash** — SmookyDev / Shaggy Donkey 90 reference with black background, tan wave, and a pulsing centered VoxVector logo.

Interactive demo: `/voxvector/loading-demo.html`.

These are UI loading treatments, not analytical methods or evidence signals.
