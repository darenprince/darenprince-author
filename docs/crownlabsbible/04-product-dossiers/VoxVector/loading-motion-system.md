# VoxVector Loading Motion System

Canonical source: `VoxVector/docs/LOADING_MOTION_SYSTEM.md`.

The VoxVector loading system uses four distinct visual states:

1. **Analysis engine** — Esca-Byte / Hard Penguin 57 reference, adapted to the VoxVector palette.
2. **Analysis workspace** — Shoh2008 / Terrible Fireant 25 reference.
3. **API startup** — Satwinder04 / Witty Starfish 81 reference.
4. **Application splash** — SmookyDev / Shaggy Donkey 90 reference with black background, tan wave, and a pulsing centered VoxVector logo.

Interactive demo: `/voxvector/loading-demo.html`.

These are UI loading treatments, not analytical methods or evidence signals.
