# VoxVector

**Category:** Crown Labs intelligence / audio research system

**Status:** Active development

**Canonical code:** `VoxVector/`

**Public target:** `voxvector.crownlabs.tech`

VoxVector is a vocal and audio analysis and deception research system. Current software performs observational acoustic, temporal, spectral, formant, voice-quality, prosodic, interaction, transcript, and baseline analysis while maintaining reliability controls, evidence provenance, candidate classification boundaries, and guarded disposition.

Current implementation is not a validated deception detector. Planned research capabilities remain part of the product roadmap even when they are not yet implemented. See the full technical dossier at `docs/crownlabsbible/04-product-dossiers/VoxVector.md` and the canonical implementation documentation under `VoxVector/docs/`.
